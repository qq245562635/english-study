# 每日英语 15 分钟

一个为我定制的英语学习网页：零基础重新开始，目标是在美国工作。

**打开网址：** https://qq245562635.github.io/english-study/

## 每天的内容（约 15 分钟）
1. **单词卡片**：250 个最常用和职场常用的单词，带美式发音、例句，按遗忘曲线自动安排复习。
2. **职场句子跟读**：8 个场景（听不懂时、自我介绍、面试、开会、邮件、求助请假、闲聊、生活）共 80 句，可以听、慢速听、用麦克风跟读打分。
3. 每天完成后自动打卡，记录连续学习天数。

## 说明
- 部署在 Cloudflare 上时，可以开启**云端同步**：学习记录保存在 Cloudflare KV，手机和电脑共用同一份进度，清缓存也不会丢。部署方法见 [DEPLOY.md](DEPLOY.md)。
- 在 GitHub Pages 上打开时没有服务器，记录只保存在浏览器里，可以在“我的”页面导出 / 导入。
- 跟读打分需要浏览器支持语音识别（电脑和安卓上的 Chrome 效果最好）。
- 词库在 `data/words.js`，句子在 `data/phrases.js`，可以直接添加。

## 发音
- 单词和句子的发音是用开源语音模型 [Kokoro](https://huggingface.co/hexgrad/Kokoro-82M)（Apache-2.0）提前生成的美式女声录音，放在 `audio/` 里。
- 新加单词或句子后，运行 `tools/gen_audio.py` 补生成录音；没有录音的内容会自动改用浏览器自带的发音。
