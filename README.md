# 每日英语 15 分钟

一个为我定制的英语学习网页：零基础重新开始，目标是在美国工作。

**打开网址：** https://qq245562635.github.io/english-study/

## 每天的内容（约 15 分钟）
1. **单词卡片**：250 个最常用和职场常用的单词，带美式发音、例句，按遗忘曲线自动安排复习。
2. **职场句子跟读**：8 个场景（听不懂时、自我介绍、面试、开会、邮件、求助请假、闲聊、生活）共 80 句，可以听、慢速听、用麦克风跟读打分。
3. 每天完成后自动打卡，记录连续学习天数。

## 说明
- 纯静态网页，不需要服务器，学习记录保存在浏览器里。
- 换设备时在“我的”页面导出 / 导入记录。
- 跟读打分需要浏览器支持语音识别（电脑和安卓上的 Chrome 效果最好）。
- 词库在 `data/words.js`，句子在 `data/phrases.js`，可以直接添加。
